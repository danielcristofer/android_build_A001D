# Android Build for Asus A001D (Zenfone Max Shot / Max Plus M2)

Este repositório contém o workflow de build automatizado para gerar a LineageOS 18.1 (Android 11) para o Asus A001D.

## 🚀 Como usar

1. Vá na aba **Actions**.
2. Clique em **Run workflow**.
3. Aguarde o processo finalizar (pode levar entre 2 a 5 horas dependendo do runner).
4. O arquivo `.zip` da ROM ficará disponível como artefato para download.

## 📁 Estrutura usada

- Device tree: [device_asus_A001D](https://github.com/danielcristofer/device_asus_A001D)
- Kernel: [kernel_asus_A001D](https://github.com/danielcristofer/kernel_asus_A001D)
- Vendor: [vendor_asus_A001D](https://github.com/danielcristofer/vendor_asus_A001D)
- Source: [LineageOS 18.1](https://github.com/LineageOS/android)
